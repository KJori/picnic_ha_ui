# Picnic Desk

A desktop Picnic shop in the Home Assistant sidebar: categories, search,
product pages, the basket as a till receipt, delivery times, checkout and
payment, orders with live tracking, and Picnic's cookbook with meal plans.
Built on the Picnic code of [picnic-web](https://github.com/MRVDH/picnic-web).

Unofficial and not affiliated with Picnic.
